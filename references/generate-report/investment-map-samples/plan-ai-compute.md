# Plan: 中美 AI 算力产业 3-10 年发展方向与产业链投资调研报告

## 任务拆解
用户要求一份深度调研报告，包含三大部分：
1. 未来 3-10 年中美各自大力发展的算力方向（大型GPU数据中心、边缘GPU、端侧GPU、芯片研发与制造、配套CPU、数据传输、材料等 + 补充方向），每个方向 0-100 打分，先美国后中国、按分数从高到低排序。
2. 各方向上会获得资金注入的产业链（上/中/下游），受益公司（Nvidia, AMD, Intel, ARM, 高通, 博通, Marvell, 摩尔线程, 寒武纪, 华为海思, 阿里平头哥 + 补充公司）。
3. 公司深度分析：财报、行业地位、产品线、研发、股价市值、未来 3-10 年变化、投资价值；上市公司附近 1.5 年周 K 线图 + 股票指标与近期财报表格。

## 阶段规划

### Stage 1 — 深度调研（加载 deep-research-swarm 技能）
并行派出 4 个研究子代理（后台）：
- R1: 美国算力发展方向（数据中心/边缘/端侧/芯片/制造/互连/电力/材料等）+ 各方向驱动因素、政策（CHIPS Act、出口管制）、投资规模。
- R2: 中国算力发展方向（同上维度）+ 国产替代、政策（东数西算、大基金）、制裁约束下的路径。
- R3: 美国产业链与公司（Nvidia, AMD, Intel, Broadcom, Marvell, ARM, Qualcomm, Micron, TSMC, 光模块/液冷/电力设备商）的行业地位、产品线、研发、竞争格局。
- R4: 中国产业链与公司（摩尔线程, 寒武纪, 华为海思, 阿里平头哥, 中芯国际, 海光信息, 中际旭创, 新易盛, 工业富联, 澜起科技, 北方华创等）。
产出：研究简报（markdown），存入 /mnt/agents/output/research/。

### Stage 2 — 行情与财务数据采集（与研究并行）
- 读取 yahoo_finance / ifind / sec_edgar 插件技能，加载对应 MCP 工具。
- 采集各上市公司：近 1.5 年周线股价、市值、PE/PB/PS、近期财报关键指标（营收、净利、毛利率、研发费用、增速）。
- 美股：Yahoo Finance / SEC EDGAR；A股：iFinD。
- 用 Python (matplotlib/mplfinance) 生成周 K 线图 PNG，存入 /mnt/agents/output/charts/。
- 产出：每公司数据 JSON + 图表 + 指标表。

### Stage 3 — 撰写报告（加载 report-writing 技能）
- 先设计大纲（含打分排序表），再分章写作子代理撰写，整合为 final.md。
- 打分逻辑：基于 Stage 1 研究证据，每方向给 0-100 发展可能性分数并说明理由。
- 引用图表（charts/*.png）与数据表。

### Stage 4 — 交付 docx（加载 docx 技能）
- 将 final.md + 图表转换为 .docx，交付 /mnt/agents/output/。
