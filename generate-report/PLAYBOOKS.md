# 10 家机构报告套路（Institution Playbooks）

基于对各机构 2025–2026 年真实报告的阅读整理。用户指定「像某家机构那样写」时，查阅对应条目，套用其结构、数据基础与图注习惯。

目录：麦肯锡 · Gartner · BCG · 贝恩 · 德勤 · PwC · IDC · Forrester · WEF · IMF/世界银行 · 风格速查表 · 选型指引

---

## 麦肯锡 McKinsey

代表样本：《Global Private Markets Report 2025》《The State of AI 2025》《Global Tech Agenda 2026》

- **数据基础**：自有全球调研（State of AI 2025：1,993 名受访者、105 个国家、2025 年 6–7 月田野、按各国 GDP 加权）+ 合作数据库（PitchBook、Preqin、CEM 等，文末列明）。
- **结构**：卷首语式开场（"What struck us most when writing this report…"）→ 反共识切入（表面低迷，实际在复苏）→ 按维度分章（私募报告按资产类别：PE / 地产 / 私募债 / 基建）→ 每章嵌 Exhibit 图表 → 作者及致谢署名 + 数据来源清单 + 编辑署名。
- **风格**：优雅长文，洞察优先；图表编号为 Exhibit；章内段落先给判断再给数据。
- **模仿要点**：写一段第一人称卷首语；每章 2–4 个 Exhibit；结尾署名到具体办公室（如「作者常驻上海与硅谷办公室」）。

## Gartner

代表样本：《Top Strategic Technology Trends 2025/2026》《Top Trends in Supply Chain Technology 2025》《Magic Quadrant》系列

- **结构**：开场定调（为什么这些趋势重要）→ 趋势归类（2025 年分「AI 要务与风险 / 计算新前沿 / 人机协同」三类）→ 逐条趋势：定义 → 为什么重要 → 量化预测 → 应用案例 → 给 CIO 的行动指向。
- **预测规范**（全行业标杆）：「By 2028, at least 15% of day-to-day work decisions will be made autonomously through agentic AI, up from 0% in 2024」——年份 + 比例 + 基线。
- **魔力象限结构**：市场定义 → 两轴（Ability to Execute × Completeness of Vision）→ 四象限（Leaders / Challengers / Visionaries / Niche Players）→ 逐厂商 strengths / cautions → 免责声明（研究观点非事实陈述，不背书任何厂商）。
- **模仿要点**：清单式编号；每条趋势字数均衡；每条必带一个量化预测和一句 CIO 行动。

## BCG

代表样本：《AI Radar 2025: From Potential to Profit》

- **数据基础**：C-level 大样本调研（1,803 名高管、19 个市场、写明行业与地区分布、田野时间 2024.9–12）。
- **结构**：悖论开场（75% 视 AI 为战略重点 vs 仅 25% 获得价值）→ 调研方法说明 → 领先者 vs 落后者对比分析 → 数字框架收尾。
- **标志**：可命名的数字框架——「10-20-70」（10% 算法、20% 数据与技术、70% 人与流程）；结论口号化，幻灯片逻辑。
- **模仿要点**：先造一个能被记住的数字口诀；全文围绕「领先者做了什么不一样的事」组织。

## 贝恩 Bain

代表样本：《Global Private Equity Report 2025》

- **结构**：董事长来信（"Dear Colleague"，人格化执行摘要）→ 年度展望 → 按价值链分章：Investments → Exits → Liquidity → Fund-raising → Returns → 专题章（生成式 AI 实战、软件投资利润率、战略要务）。
- **图表规范**（全行业最严）：每张图带编号 + 判断句标题（"Buyout fund-raising declined in every region but Asia"）+ Notes（口径：剔除 add-on、含 pending 交易、金额阈值）+ Sources（Dealogic; Preqin; Bain analysis）。
- **风格**：交易级细节（具体案例如 KKR 收购 Cotiviti），务实冷峻。
- **模仿要点**：价值链分章；每章一张严格图注的图；案例给到金额与交易方名字。

## 德勤 Deloitte

代表样本：《Tech Trends 2025》

- **结构**：中心论点（「AI 正成为像电力一样的基础设施」）→ 六大趋势逐章展开（空间计算、AI 演进、硬件复兴、IT 职能变革、后量子密码、核心系统现代化）→ 章内引第三方数据佐证 → 末尾 Strategic Takeaways 行动清单。
- **风格**：教科书式全面，类比驱动（用 Y2K 类比后量子密码迁移）。
- **模仿要点**：给一个贯穿全文的中心类比；每章结构对称；末尾列 5–6 条 Takeaways。

## 普华永道 PwC

代表样本：《28th Annual Global CEO Survey 2025》

- **数据基础**：超大样本调研（4,701 名 CEO、109 个国家 / 地区、田野时间 2024.10–11）。
- **结构**：悖论式大数字开场（60% 看好增长 vs 42% 认为公司撑不过十年）→ 主题分章（增长信心、GenAI 实效、气候投资回报、跨界竞争、信任）→ 每章全球数字 + 区域 / 行业切片 → 分角色 implication（战略者 / 投资者 / 董事会）。
- **风格**：新闻化，标题即大数字；配合达沃斯发布的传播节奏。
- **模仿要点**：标题里直接放数字；每章必给区域与行业切片；结尾按角色写 implication。

## IDC

代表样本：Worldwide AI Infrastructure Tracker / Worldwide Spending Guide 系列

- **结构**：市场规模现状（2025 年 AI 基础设施支出 3,180 亿美元）→ 增速（同比翻倍）→ 预测（2026 年 4,870 亿美元、+53%；2029 年破万亿、5 年 CAGR 约 31%）→ 结构拆分（服务器占 97.6%）。
- **核心**：**口径极严谨**——明确定义统计范围（AI 基础设施只算服务器 / 存储 / 网络硬件，不含软件与服务）。写市场数据稿时先写口径定义，再写数字。
- **模仿要点**：定义先行；规模 + 增速 + CAGR + 结构拆分四件套；每个数字标 Tracker 版本与发布时间。

## Forrester

代表样本：《Predictions 2026》系列（AI、网络安全、CX、支付、营销代理商）

- **结构**：按领域各出一份预测报告；每份 3–5 条编号预测，每条：大胆断言（带数字，如「三分之一企业」「15% 裁员」）→ 驱动证据 → 给对应角色（CISO、CX 负责人）的应对建议。
- **风格**：断言先行、态度鲜明，敢于给可证伪的判断。
- **模仿要点**：预测数量少而狠；每条允许「与共识相反」；配一条「如果我们错了，会是因为…」更佳。

## WEF

代表样本：《Global Risks Report 2025》《Future of Jobs Report 2025》

- **数据基础**：千家企业 / 专家调研（Future of Jobs：1,000+ 雇主、55 个经济体、22 个行业集群、覆盖 1,400 万员工）。
- **结构**：调研方法 → 宏观驱动因素框架（技术变革 / 经济不确定 / 地缘分化 / 绿色转型 / 人口结构五大因素）→ 排名与矩阵（2 年 / 10 年风险榜、增长 / 衰退岗位榜）→ 量化预测（2030 年净增 7,800 万岗位、39% 核心技能将变化）→ 应对策略。
- **风格**：全球公共议题视角，多时间窗对比（2 年 vs 10 年）。
- **模仿要点**：五因素驱动框架；用排名榜和矩阵承载结论；给短期与长期两个时间窗。

## IMF / 世界银行

代表样本：IMF《World Economic Outlook》(2025.4 / 2025.10)、世行《Global Economic Prospects》(2025 / 2026)

- **结构**：标题即判断（"Global Economy in Flux, Prospects Remain Dim"）→ 总览章（全球前景与政策：增长 / 通胀 / 贸易 / 金融风险）→ 专题章 2–3 个（如「新兴市场韧性：运气还是政策？」「产业政策：权衡取舍」）→ 统计附录 / 数据表。
- **学术规范**：章节内嵌 Box 专题（署名作者）、Figure 带完整 Sources 与 Note（含缩写表 AE / EMDE 等）、文末学术参考文献；风险段固定出现（"Risks are tilted to the downside"）→ 政策建议收尾（分货币政策 / 财政 / 结构性改革）。
- **模仿要点**：总-分专题式切法；Box 承载题外深度；风险段固定句式；建议按政策工具分类。

## 风格速查表

| 机构 | 数据基础 | 标志性构件 | 叙事风格 |
|---|---|---|---|
| 麦肯锡 | 自有调研 + 合作库 | Exhibit 图表、卷首语 | 优雅长文，洞察优先 |
| Gartner | 分析师判断 + 量化预测 | 魔力象限、预测三要素 | 清单式：定义→预测→行动 |
| BCG | C-level 调研 | 数字框架（10-20-70） | 幻灯片逻辑，口号化 |
| 贝恩 | 第三方库 + 自有分析 | 董事长来信、图注规范 | 交易级细节，务实冷峻 |
| 德勤 | 专家 + 调研 | 六趋势 + Takeaways | 教科书式全面 |
| PwC | 超大样本 CEO 调研 | 悖论大数字开场 | 新闻化，区域/行业切片 |
| IDC | Tracker 统计口径 | 市场规模 + CAGR | 数据稿，口径极严谨 |
| Forrester | 分析师预测 | 分领域编号预测 | 大胆断言 + 应对建议 |
| WEF | 千家企业调研 | 风险矩阵、排名 | 全球公共议题，多时间窗 |
| IMF/世行 | 成员国数据 + 模型 | 章节 + Box + 统计附录 | 学术规范，政策建议收尾 |

## 选型指引（用户没指定机构时）

| 报告目的 | 建议对标 |
|---|---|
| 明年该关注哪些技术 / 趋势 | Gartner（清单 + 量化预测）或德勤（中心类比 + Takeaways） |
| 一个行业的年度全景盘点 | 贝恩（价值链分章 + 严格图注）或麦肯锡（维度分章 + Exhibit） |
| 有一手调研数据要发布 | BCG（悖论 + 数字框架）或 PwC（大数字 + 区域切片） |
| 市场规模与支出预测 | IDC（口径先行 + CAGR 四件套） |
| 少而狠的判断、敢下结论 | Forrester（编号预测 + 应对建议） |
| 宏观 / 政策 / 公共议题 | IMF·世行（总-分专题 + Box + 政策建议）或 WEF（五因素 + 排名矩阵） |
